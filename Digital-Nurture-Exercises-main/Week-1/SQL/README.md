Inventory Management System - Exercise 1
Problem

An inventory system is needed to efficiently store, update, and manage warehouse products using proper data structures.

🧠 Why Data Structures?

Data structures help in:

Fast data storage and retrieval
Efficient handling of large inventory
Easy add, update, and delete operations
🏗️ Design
Product Class
productId
productName
quantity
price
📊 Data Structure Used

HashMap (productId → Product)

Fast access and updates
Ideal for large datasets
⚙️ Operations
Add Product → O(1)
Update Product → O(1)
Delete Product → O(1)
Conclusion

Using HashMap makes the inventory system fast, efficient, and scalable.
