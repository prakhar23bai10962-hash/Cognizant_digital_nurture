LibraryManagement

This project is a Spring-based Library Management application developed to understand core Spring concepts like IoC, Dependency Injection, AOP, and Spring Boot basics.

Created a Spring Boot application with REST API, entities, repositories, and H2 database integration.

Technologies Used
Java
Maven
Spring Framework
Spring Boot
AOP
H2 Database
Purpose

To understand and implement core Spring concepts step-by-step from basic XML configuration to Spring Boot REST API development.
