# Exercise 2 - Error Handling

This exercise demonstrates the use of exception handling in PL/SQL using stored procedures.

## Scenarios Covered

### 1. SafeTransferFunds

Transfers money between two accounts and handles errors such as insufficient balance by rolling back the transaction.

### 2. UpdateSalary

Updates an employee's salary by a given percentage and displays an error message if the employee does not exist.

### 3. AddNewCustomer

Adds a new customer to the database and prevents duplicate customer IDs from being inserted.

## Files Included

* Scenario1_SafeTransferFunds.sql
* Scenario2_UpdateSalary.sql
* Scenario3_AddNewCustomer.sql

## Tools Used

* Oracle PL/SQL
* Visual Studio Code

This exercise helped in understanding exception handling, transaction management, COMMIT, and ROLLBACK operations in PL/SQL.
