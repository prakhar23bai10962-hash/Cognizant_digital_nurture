# Cognizant Digital Nurture Exercises

Welcome to my portfolio repository for the **Cognizant Digital Nurture** Java Full-Stack Developer program. This repository contains all the hands-on labs (HOLs), assignments, and practice exercises completed over the 8-week curriculum.

## 🚀 Curriculum Overview

- **Week 1-3:** Data Structures, Algorithms, PL/SQL, and TDD with JUnit/Mockito
- **Week 4:** Logging (SLF4J, Logback) and Automation Testing
- **Week 5:** Spring Core and Maven dependencies
- **Week 6:** Hibernate and Spring Data JPA Configuration
- **Week 7:** Spring Boot, REST APIs, and Microservices Architecture
- **Week 8:** React Desktop/Web Apps, Git Client Apps, Docker, Cloud Basics, and GenAI concepts

## 💻 Tech Stack

- **Backend:** Java 17, Spring Boot, Hibernate, Spring Data JPA
- **Frontend:** React, HTML/CSS/JavaScript
- **Database:** H2 (In-memory development), MySQL
- **Tooling:** Maven, npm, Git, JUnit, Mockito

## 🏃 Getting Started

### Backend Projects
Most Java/Spring projects in this repository are configured to use an **In-Memory H2 Database** (`jdbc:h2:mem:...`) for out-of-the-box execution without local database dependencies.
Simply run them as Maven Spring Boot applications or directly execute the `main` methods in your preferred IDE.

### Frontend Projects
Navigate to any React folder in `Week-08` and run:
```bash
npm install
npm start
```
